# Completed read prefixes

This folder owns the opt-in source-format-2 observation prefix. The writer records completed reads and staging frontiers privately; committed sidecar entries name actual native log rows. Reservation order is not completion order. Repeated, nested, aggregate and non-scalar writes are unsupported.

The codec admits only inert bounded data; each frame counts actual committed trace rows, so deleting a captured prefix is refused even before a native log is joined. The shared cause/PROV reader also reconciles the full captured inventory against actual native rows. Partial output coverage limits forward impact without downgrading an independently complete backward explanation. An admitted prefix is a set of possible contributors observed before a write, never proof of expression use or producer authenticity. Existing overall read-source byte limits include the sidecar; path hashing and repeated privacy comparisons reserve query work before scanning.

An unavailable output candidate or an unreleased read leaves that read's forward linkage incomplete without inventing an edge. Different frames and frontiers before the read are excluded from that association; they do not turn unrelated known evidence into an unknown link.
