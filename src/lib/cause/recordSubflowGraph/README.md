# Subflow observation graph

This library projects separately admitted handoffs into the existing cause
graph. `parents.ts` binds the actual seed or mapping write and its saved source
cutoff. `sources.ts` reuses the canonical slice at that cutoff and charges each
source resolution before work, even when no edge results. `children.ts` derives
inverse joins through the same parent authority.

Only the existing authorized scope loader performs IO. Query-owned memoization
shares admitted inspections; there is no second walker or global reverse index.
Forward-only inventory, load and work limits do not change backward root
eligibility. A reached native seed without input evidence keeps a boundary gap;
an independent later child constant does not inherit that uncertainty.

Observed prefixes produce conservative stage edges and a gap. An empty prefix
is not proof of no external source. Fan-out scope observations remain
nontraversable, with explicit collection/slot references; no root key or array
index dependency is invented. Adjacent tests preserve these distinctions and
local graph behavior.
