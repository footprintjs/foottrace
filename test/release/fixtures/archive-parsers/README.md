# Archive parser agreement fixtures

Data-only tar/gzip fixtures from the independent Foottrace54 reader, retained byte-for-byte with SHA256 metadata. The adjacent release archive-parser test compares the real inspector with npm11.19.0 publish-manifest reading through pacote, offline and with scripts disabled. It never calls publish or obtains a token. Noncanonical tar headers are refused even when the two parsers happen to agree; format-admitted manifests must agree on name, version, absence of effective publishConfig and the actual npm selection manifest.tag || defaultTag. Native release/publish separately require deep equality with the pinned source manifest except version: the T1/T2/T3 tag-override fixtures pass the format profile but fail that source boundary. The five T fixtures are additional independent reader data. JSON/BOM fixtures retain their reader comparison; concatenated gzip is now explicitly outside the one-member flags-zero profile. USTAR prefix/PAX refusals are named archive-profile; the original bytes and hashes are preserved.
