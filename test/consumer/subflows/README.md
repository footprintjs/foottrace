# Real native producer to reader proof

The existing downstream hosted workflow copies `verify-native.mjs` and the
reviewed producer's fixed public `produce.cjs` beside each other in a neutral
consumer. Before execution, that job admits both source-built archives and
proves its strict lock, installed members and single physical record package.
Run `node verify-native.mjs` from that neutral installation. Never execute this
script from a source checkout with a different development dependency image.

The producer builds real public charts. The reader adapts their actual native
snapshots into partial inventories and checks mapped inputs/outputs, saved
cutoffs before a later overwrite, literal keys, inverse edges, reordered
fan-out, nested collection ownership, default-off flags and private serving.
Both installed CJS and ESM reader exports consume the same real records.
Expected observed links remain conservative; whole-scope collections stay
nontraversable. No hand-authored handoff DTO replaces the real producer.

This script is a source protocol fixture, not a package export or an artifact
inspector. Its result says which scenarios actually ran. Source/archive/run
identities and physical-install evidence belong to the surrounding reviewed
job. Source version equality is not registry byte identity, and this two-package
proof is separate from any major-version consumer cohort or release approval.
